== Importing Existing PDF Files

この章では、ドキュメントに PDF を取り込む方法を説明します。

Asciidoctor PDF は、PDFページを取り込むために `image::` マクロを使用します。
これは画像へ変換することを意味せず、元の PDF のページをそのまま出力する PDF へ取り込みます。

=== Specifying the Source PDF

相対パスを指定する場合は、通常の画像と同様に `IMAGES_DIR` を基準に解決されます。このサンプルの既定値では
`images/` なので、たとえば次のように置けます。

[source,text]
----
images/appendices/qualification-report.pdf
----

この PDF を取り込む場合は以下のように `image::` マクロを記載します。

[source,asciidoc]
....
image::appendices/qualification-report.pdf[pages="1..24"]
....

=== Importing One Page

`page` 属性で取り込むページ番号を指定します。ページ番号は1から始まります。

[source,asciidoc]
....
image::appendices/qualification-report.pdf[page=3]
....

`page` を省略した場合は、1ページ目を取り込みます。

=== Importing Multiple Pages

複数ページを取り込む場合は `pages` 属性を使用します。カンマでページ番号を区切り、
`..` で範囲を指定できます。

[source,asciidoc]
....
image::appendices/qualification-report.pdf[pages="1,3,5..8"]
....

PDF 全体を付録として取り込む場合も、最終ページを明示して範囲を指定します。

[source,asciidoc]
....
image::appendices/qualification-report.pdf[pages="1..24"]
....

=== Add a TOC entry for an imported PDF

インポートした PDFは `[%notitle]` の見出しを付加することで、目次に追加することができます。

以下の例では、「Qualification Report」という章題は本文には表示されませんが目次に表示され、
インポートされたPDFの最初のページへのリンクとして機能します。

[source,asciidoc]
....
[%notitle]
== Qualification Report
image::appendices/qualification-report.pdf[page=3]
....
